icrypt
the field console for chess steganography

Messages that play
as chess games.

i-crypt turns any text into a perfectly legal, playable game of chess. Post the game anywhere Chess.com, Lichess, a forum, a printed score and only whoever holds the right key ever sees the real message.

hiding the word… 

We just hid the word SECRET in that game every move was a legal, ordinary chess move. That is the whole trick, live.

the operation

1. e4 · write

Type the message

Add a key if you want one a password, or a FEN position agreed beforehand. No key means anyone can read it.

2. Nf3 · play

Get a real game

The tool composes a legal game whose moves carry your bits. Import the PGN anywhere and play it naturally.

3. Qh4 · recover

Paste, watch, reveal

Whoever you told the key to pastes the game back. The replay runs, and the message types itself out.
